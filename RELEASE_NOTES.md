# SPPACEU — Mapping Corruption Exposure in Ukraine

A research workflow for studying public practices of exposing corruption on YouTube in Ukraine.

- Collects channel, video, playlist, and membership metadata.
- Builds the multi-sheet workbook used by contextual AI analysis.
- Includes alternative video-screening notebooks, audio collection, transcript coding, and optional semantic source search.
- Replaces machine-specific paths with configurable directories and starts external processing in preview mode.
- Includes offline checks for workbook compatibility and mocked response handling.

**Execution:** Supply research inputs and credentials to run live analysis. FFmpeg and any required JavaScript runtime must be installed separately for media downloads. Transcription between audio collection and transcript coding is a separate step.
